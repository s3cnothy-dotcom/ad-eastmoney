# ad-eastmoney
自动隐藏东方财富股吧的大部分广告


一个实用的油猴（Tampermonkey）脚本，专门针对 https://guba.eastmoney.com/ 及其子页面（如个股股吧列表页）优化：隐藏各类广告、推广、APP下载栏、右侧/底部推荐
优化布局：加宽主内容区、简化侧边栏
移除弹窗提示、浮动按钮等干扰元素
自动清理动态加载的内容

使用方法：安装 Tampermonkey（Chrome/Edge 扩展）
点击扩展图标 → 创建新脚本
删除默认内容，粘贴以上代码
保存（Ctrl+S）

效果：大幅减少右侧推广和APP诱导
帖子列表更干净、阅读区域更宽
动态加载的新内容也会被自动清理
